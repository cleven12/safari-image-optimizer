# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, email security concerns to: **security@clevengodson.online**

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 48 hours and work with you to verify and fix the issue before any public disclosure.

## Security Measures

- CodeQL static analysis runs on every PR and weekly
- Dependency review blocks known vulnerable packages
- Dependabot monitors for security updates
- No sensitive data is logged or stored by this tool
